# SAP 구매 및 회계 처리 프로젝트

ABAP 기반 CBO 프로그램으로 SAP MM 구매 프로세스와 회계 처리를 구현한 프로젝트입니다.

- 개발 기간: 2025.11.17 ~ 2025.12.14
- 주요 기술: ABAP, SAP MM/FI, Module Pool, ALV

## 주요 구현 내용
- 구매오더·입고·송장 처리 및 자재문서·회계전표 연계
- 기준정보와 거래 데이터 분리 및 헤더·아이템 테이블 설계
- 외주임가공 제품의 BOM 기반 부재료 소비
- 입고 취소 시 역분개 전표 생성
